## About

Software engineer building full-stack products end to end: frontend, backend, infrastructure, and the operational plumbing in between. I move across TypeScript/Next.js, Go, Python and MQL5 depending on what a problem needs, rather than staying inside one stack.

Most of the work sits where **product engineering** meets **systems thinking**: booking engines with real-time room state, POS systems that survive flaky networks, homelab infrastructure that heals itself, and bots that run unattended for months. The common thread is shipping things that work in production, not just in a demo.

**Open to** full-time roles, freelance and contract work, and conversations about system design.
